# Amazon Sales Analysis – Tableau Dashboard

## 📌 Project Overview
This project analyzes Amazon sales data using Tableau to identify sales trends, product performance, and customer purchasing patterns.

## 🎯 Project Objectives
- Analyze overall sales performance.
- Identify top-performing products.
- Understand sales trends.
- Generate meaningful business insights.
- Present findings through interactive visualizations.

## 🛠️ Tools & Technologies
- Tableau
- Microsoft Excel / CSV
- Data Visualization
- Data Analysis

## 📂 Project Files
- `amazon_sales_dataset.csv` – Dataset used for analysis.
- `Book1.twbx` – Tableau dashboard workbook.

## 📊 Dashboard Preview
Interactive Tableau dashboard developed to explore Amazon sales data and visualize important business metrics.

## 💡 Key Learnings
- Data analysis and interpretation.
- Creating interactive dashboards.
- Identifying sales trends.
- Presenting business insights through visualizations.
